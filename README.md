# Fisch!

Static site, no build step. Deploy on Vercel: import this repo, Framework Preset "Other", leave build/output settings empty. `index.html` is served at `/`.

## Fischen!

`fischen.html` is a small browser fishing game (canvas + `fischen.js`/`fischen.css`). Every catch is one of the site's GIFs/PNGs. Progress is saved in `localStorage`.
